# 💼 EVOLUI — Jovem Aprendiz

> **Cresça por dentro. Avance por fora.**

## 📌 Sobre o projeto

O **EVOLUI** é um sistema de oportunidades desenvolvido para conectar **jovens que buscam sua primeira oportunidade de trabalho** a **empresas que procuram candidatos para vagas de Jovem Aprendiz**.

O projeto foi desenvolvido como um **MVP (Produto Mínimo Viável)** utilizando Python, Tkinter e Programação Orientada a Objetos.

## 🎯 Objetivo

O objetivo do sistema é facilitar a busca por oportunidades de Jovem Aprendiz e ajudar empresas a encontrar jovens interessados em suas vagas.

## ⭐ Funcionalidades do MVP

### 👩‍🎓 Jovem

* Cadastro e login;
* Visualização de vagas;
* Visualização dos detalhes das vagas;
* Candidatura às vagas;
* Visualização das candidaturas.

### 🏢 Empresa

* Cadastro e login;
* Cadastro de vagas;
* Visualização das vagas cadastradas;
* Visualização dos candidatos.

## 💻 Tecnologias utilizadas

* Python
* Tkinter
* Programação Orientada a Objetos (POO)
* MySQL
* Git e GitHub
* Visual Studio Code

## 🗂️ Organização do projeto

O sistema possui arquivos separados de acordo com suas funções, incluindo o arquivo principal, conexão com o banco de dados, modelos e telas da aplicação.

## ▶️ Como executar

1. Instalar o Python.
2. Abrir a pasta do projeto no Visual Studio Code.
3. Instalar as dependências necessárias.
4. Configurar o banco de dados.
5. Executar o arquivo principal:

```bash
python main.py
```
